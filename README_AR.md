# GoTasks - نظام إدارة المهام الموزع

نظام لإدارة المهام الموزعة مبني بلغة Go يسمح لخادم رئيسي بالتحكم في عدة أجهزة فرعية عبر HTTP. النظام يدعم إيقاف التشغيل عن بُعد، معالجة الملفات الموزعة، وتغيير خلفية سطح المكتب عن بُعد.

## البنية المعمارية

### الخادم الرئيسي (`Master/main.go`)
- يعمل على المنفذ **9080**
- يعمل كعقدة تحكم مركزية
- يقرأ إعدادات الأجهزة الفرعية من `config.json`
- يوزع المهام على الأجهزة الفرعية ويجمع النتائج

### الخادم الفرعي (`Slave/main.go`)
- يعمل على المنفذ **9070**
- يعمل على كل جهاز مستهدف
- يستقبل وينفذ الأوامر من الخادم الرئيسي
- يدعم أنظمة التشغيل Windows و Linux

## الإعداد

أنشئ ملف `config.json` في مجلد Master:

```json
[
  {
    "ip": "192.168.1.100",
    "slave": 1,
    "slave_name": "pc1"
  },
  {
    "ip": "192.168.1.101",
    "slave": 2,
    "slave_name": "pc2"
  }
]
```

## نقاط النهاية (Endpoints)

### نقاط الخادم الرئيسي (منفذ 9080)

| النقطة | الطريقة | الوصف |
|--------|---------|-------|
| `/Shutdown` | POST | إيقاف تشغيل جهاز بعيد |
| `/Background` | POST | تغيير خلفية سطح المكتب على جهاز بعيد |
| `/FileChunk` | POST | توزيع معالجة الملفات على الأجهزة الفرعية |

### نقاط الخادم الفرعي (منفذ 9070)

| النقطة | الطريقة | الوصف |
|--------|---------|-------|
| `/Shutdown` | POST | تنفيذ أمر إيقاف التشغيل |
| `/Background` | POST | استقبال صورة وتعيينها كخلفية |
| `/FileChunk` | POST | معالجة جزء من بيانات ملف |

## المميزات

### 1. إيقاف التشغيل عن بُعد
أرسل طلب POST للخادم الرئيسي باسم الجهاز الفرعي لإيقاف تشغيله.

```bash
curl -X POST http://localhost:9080/Shutdown -d "pc1"
```

### 2. معالجة أجزاء الملفات
يوزع أسطر الملف على عدة أجهزة فرعية لحساب تكرار الأحرف بشكل متوازي.

```bash
curl -X POST http://localhost:9080/FileChunk -d "/path/to/file.txt"
```

### 3. تغيير الخلفية عن بُعد
يرسل صورة لجهاز فرعي ويعينها كخلفية لسطح المكتب.

```bash
curl -X POST http://localhost:9080/Background \
  -H "Content-Type: application/json" \
  -d '{"path": "/path/to/image.jpg", "name": "pc1"}'
```

## كيف يعمل النظام

### تدفق إيقاف التشغيل
1. الخادم الرئيسي يستقبل اسم الجهاز عبر `/Shutdown`
2. يبحث عن IP الجهاز من `config.json`
3. يوجه الطلب إلى `http://<slave_ip>:9070/Shutdown`
4. الجهاز الفرعي ينفذ أمر إيقاف التشغيل المناسب:
   - **Windows**: `shutdown -s -t 0`
   - **Linux/macOS**: `shutdown now`

### تدفق معالجة الملفات
1. الخادم الرئيسي يستقبل مسار ملف عبر `/FileChunk`
2. يقرأ الملف سطر بسطر
3. كل سطر يُرسل لجهاز فرعي مختلف عبر `/FileChunk` (نظام دوري)
4. كل جهاز فرعي يحسب تكرار الأحرف في الجزء الخاص به
5. الخادم الرئيسي يجمع كل النتائج ويعيد إجمالي تكرار الأحرف

### تدفق تغيير الخلفية
1. الخادم الرئيسي يستقبل JSON يحتوي على مسار الصورة واسم الجهاز عبر `/Background`
2. يقرأ ملف الصورة وينشئ طلب multipart form
3. يرسل الصورة إلى نقطة `/Background` في الجهاز الفرعي
4. الجهاز الفرعي يحفظ الصورة في `./data/Background/uploaded_<filename>`
5. ينفذ أوامر خاصة بنظام التشغيل:
   - **Windows**: يستخدم PowerShell مع API `SystemParametersInfo` لتعيين الخلفية
   - **Linux**: يستخدم `gsettings` لتعيين خلفية سطح مكتب Cinnamon

## كيفية التشغيل

### تشغيل الخادم الفرعي
```bash
cd Slave
go run main.go
```

### تشغيل الخادم الرئيسي
```bash
cd Master
go run main.go
```

### بناء الملفات التنفيذية
```bash
cd Slave && go build -o slave
cd Master && go build -o master
```

## المتطلبات

- Go 1.18+
- **أجهزة Windows**: PowerShell متاح (موجود افتراضياً على Windows 7+)
- **أجهزة Linux**: بيئة سطح مكتب Cinnamon مع `gsettings`

## الإصلاحات المطبقة على مشكلة الخلفية في Windows

تم إصلاح المشاكل التالية في دالة `doBackground`:

1. **فصل اسم الملف**: تم إضافة `_` بين `uploaded` واسم الملف لتجنب تداخل المسارات
2. **إغلاق الملف**: تم إغلاق الملف (`dst.Close()`) قبل تنفيذ أمر PowerShell لضمان أن النظام لا يرفض الوصول للملف
3. **معالجة الأخطاء**: تم إضافة `return` عند فشل `filepath.Abs` لمنع استمرار التنفيذ بمسار غير صحيح
